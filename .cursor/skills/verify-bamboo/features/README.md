# Bamboo verification map

Start with a fresh browser context, default Grove,390x844, normal motion unless the feature specifies reduced motion. Entry is public, no private account/state. Source of truth is the observed UI and actual pixels, not model success.

- [Explore and look](explore.md): Enter, four zone settings, drag/touch, reset.
- [Guided tour](tour.md): five physical stops, previous/exit/finish, changing worker counts.
- [Sound](sound.md): initial mute, unmute, zone crossfade, mute again.
- [Performance](performance.md): exact build/renderer/viewport, frame windows and preserved scene counts.

Use isolated contexts. Keep evidence after cleanup. Mark unexecuted paths pending; don't weaken assertions to make a test green.
